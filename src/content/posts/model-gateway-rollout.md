## 문제

- 팀마다 쓰는 모델과 비용이 다르고, 누가 얼마나 쓰는지 한곳에서 보이지 않음
- 정책(팀별 한도 · 허용 모델)을 화면에서 손으로 바꾸면 무엇이 바뀌었는지 남지 않음

## 고른 것과 버린 것

- 조직을 팀 단위 작업 공간으로 나누고, 정책 변경은 "계획 파일 → 미리 실행 → 적용 → 다시 조회" 순서의 스크립트로만 수행
- 게이트웨이에 딸린 채팅 화면은 제외 — 대화가 브라우저에만 저장되고, 팀별로 모델을 걸러 보여 줄 수 없고, 문서 파일을 다루지 못함. 직접 띄우는 채팅 도구를 연결
- 특정 공급자 하나로 고정하는 설정은 제외 — 그 공급자의 상태가 나빠지면 전체가 멈춤

## 측정값

- 시범 16명(작업 공간 6개) → 전사 41명
- 조직 인원 상한 20명 → 50명(공급사 지원 창구에 요청해 상향)
- 한 달 사용 분석: 비싼 요청 7.1%가 비용의 65.6%를 차지 → 업무별로 모델을 나눠 쓰는 안을 보고

## 한계와 다음

- 한도 체계를 두 번 변경. 사람별 한도 → 팀 월 예산 → 팀 지갑과 개인 한도
- 채팅 도구는 쓰는 사람이 적음. 도입 효과로 말할 수 있는 것은 게이트웨이 쪽
- 예산과 한도 금액은 내가 정한 것이 아님
