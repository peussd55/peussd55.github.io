## 사내 운영팀용 IP 등록 봇(시범 단계)

- 본인 확인(등록된 번호 + 문자 인증) → IP 검증 → 고객사 서버 방화벽 반영 → 7일 뒤 자동 차단
- 모델이 인증을 건너뛰고 등록을 부르던 문제를 6단계 상태 관리와 단계별 도구 노출로 차단
- 방화벽 연동이 2분 9초 멈추던 원인(연결 단계에는 제한 시간이 걸리지 않음)을 찾아 12초 상한 적용
- 운영팀 시험 통화와 의견 반영까지 완료, 운영 반영은 승인 대기

## 모델 7종 비교 평가

- 같은 평가 묶음으로 사내 서빙 모델(97.6%)과 외부 모델 7종을 자동 비교
- 모델 공급자를 봇마다 골라 쓰고, 실패하면 사내 모델로 넘어가도록 구성

## 웹사이트 수집 → 기존 지식 대조

- 300쪽을 수집해 기존 지식과의 충돌 33 · 보강 108 · 신규 99건을 분류
- 초안을 만든 모델이 없는 문장을 지어내, 사람 검토를 반드시 거치도록 지정

## 도메인 평가 체계

- 정답지 71건을 모델 출력이 아니라 실제 조회 결과로 만들어 사람이 전수 검수
- "확신에 찬 오답"은 정확도와 따로 세어, 한 건이라도 나오면 불합격으로 판정
